# BilibiliDownloader v2.2.0 发行说明

## 更新说明

本次为重大内容更新（版本号第二位递增），重构了多类型混合勾选时的解析与选集逻辑。

### 多类型混合选集重构

- 当一次勾选同时包含「有分集」视频（番剧 / 影视 / 课程 / 合集 / 多分P）与「无分集」视频时，不再为每个容器各起一个线程去覆写同一个选集页（旧逻辑下只有最后一个容器的分集会被显示，前面的选择全部丢失）。
- 现在按用户勾选顺序**依次解析**每个有分集的视频供挑选；每段各自独立保留勾选状态。
- 选集过程中，底部「加入下载队列」按钮切换为「上一个 / 下一个」，可来回切换各分集视频；全部选完后按钮恢复，所有分集与无分集视频统一进入下载选项并入队。
- 单个有分集容器（非混合）仍沿用原有单段选集流程，不改变既有习惯。

### 搜索混合勾选适配

- 搜索结果中同时勾选 UP主 与视频 / 番剧时，UP主空间也作为一段接入同一套顺序选集流程：逐个解析各 UP主的空间视频 / 番剧分集供挑选，底部按钮切换为「上一个 / 下一个」，全部选完统一入队。
- 单个 UP主 或单个番剧仍沿用原有的单段入口，不改变既有习惯。

### 内联页标题显示上下文

- 浏览 / 搜索 / 关注 / 批量解析等内联页的标题现在会显示具体对象：UP主空间显示「UP主名」的个人空间，分集选择显示 选择你想下载「视频标题」的分集；切换界面语言时标题同步刷新。

### 用户协议多语言与自动切换语言

- 首次启动的用户协议在正文上方用水平排列的语言按钮罗列简体中文 / 繁體中文 / English / 日本語，点击哪种语言就只切换显示那一种协议正文（非四语并排）。
- 点选任一语言即自动切换软件界面语言并持久化，无需再到设置页手动切换；仍需将当前语言协议正文滚动阅读至底部才能点「同意并继续」。

### 批量解析内联页适配

- 批量解析命中的多个分集容器接入同一套顺序选集流程，与浏览页 / 搜索页的体验保持一致。
