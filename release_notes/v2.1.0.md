# BilibiliDownloader v2.1.0 发布说明

v2.1.0 在 PySide6 + QFluentWidgets 基础上进一步打磨 Fluent 交互，并将侧边栏各类浏览入口改为「主界面内联切换」，同时新增直播录制「录制起点」时移能力。

## 内容更新
- **全新 Fluent 风格界面**：设置窗口、对话框、侧边栏、下载队列全部基于 QFluentWidgets 重写，随明 / 暗主题自动适配；下载队列采用原生虚拟化列表，大量任务下保持流畅。
- **侧边栏导航内联化**：「我的」（收藏夹 / 稍后再看 / 历史记录 / 关注 / 追番）与「发现」（每周必看 / 排行榜 / 搜索 / 音乐 / 直播中心）全部改为在主窗口内联切换，不再弹出子窗口；内容页左上角提供返回按钮，下载队列全程可见，并支持分页、全选计数与关键词搜索。
- **直播录制支持「录制起点」时移**：可选当前位置 / 5·15·30 分钟前 / 1·2 小时前 / 从直播开始；时移不可用时自动回退当前位置，录制不中断。
- **跨平台自动构建**：推送 `v*` 标签后 CI 自动构建发布 Windows 安装版 + 便携版、Linux AppImage（x86_64 / aarch64）、macOS .dmg / .app.zip（arm64 / x86_64）。

## 修复 / 优化
