# BilibiliDownloader v2.0.0 发布说明

## 内容更新
- **全新 GUI（PySide6 + QFluentWidgets 重构）**：界面整体由 CustomTkinter 重写为 PySide6 + QFluentWidgets（Fluent / WinUI 风格），相较 1.0.0 更加流畅、现代化，并完整支持明 / 暗主题与高分屏。
- **跨平台安装包**：现已由 GitHub Actions 自动构建并发布 Windows / macOS / Linux 三平台安装包（Windows 安装版 + 便携版、Linux AppImage、macOS .dmg / .app.zip）。
- **统一分页与浏览器跳转**：搜索与各列表复用分页逻辑，列表项新增「在浏览器中打开」跳转按钮；每周必看 / 排行榜改为先弹「加载中」再后台拉取，消除卡顿错觉。
- **批量解析统一**：UP 主空间等可翻页来源统一走分页选择框；分页栏显示「第 N / M 页」，输入超范围自动钳制到末页。
- **主题防抖**：强调色 / 明暗切换加入 140ms 防抖提交器，缓解拖动取色器造成的卡顿。
- **项目更名**：统一为 BilibiliDownloader（打包产物名、窗口标题、应用名一致）。
- **许可证合规**：补齐 GPL-3.0 的 LICENSE / NOTICE，明确衍生作品署名与许可。
