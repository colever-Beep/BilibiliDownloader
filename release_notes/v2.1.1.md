# BilibiliDownloader v2.1.1 发布说明

## 内容更新
- **默认强调色改为软件图标同款粉色**：默认强调色由原本的绿色改为图标粉色 `#f07090`，按钮、高亮、侧边栏等主操作元素统一跟随，观感更贴近品牌；仍可在「设置 → 基本设置 → 强调色」自由取色或跟随系统。
- **新增内置更新功能**：支持稳定版 / 测试版双通道、自动检查更新、GitHub Release 版本比对、Markdown 更新日志预览，以及带进度 / 速度 / 剩余时间的后台下载与开机自动检查。
- **安装包瘦身**：Windows 安装版 / 便携版内置的 FFmpeg 精简为仅含 `ffmpeg` 与 `ffprobe`（去除未使用的 `ffplay`，单个即 160MB+），并改用体积更小的 essentials 构建；ffprobe 保留以保证 yt-dlp 内嵌元数据后处理正常。
