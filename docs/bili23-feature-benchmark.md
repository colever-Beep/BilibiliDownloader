# 与 bili23 原版功能对标分析

> 对标对象：`D:\VScode\bili23_example`（Bili23-Downloader v2.12.1，GPLv3 原版）
> 本项目：BilibiliDownloader（衍生版，当前 v2.2.0 开发中）
> 生成时间：2026-11-22
> 结论先行：衍生版在**下载引擎、直播录制、内置更新、UI 活泼化**上已反超原版；
> 原版仍有约 12 项值得借鉴的功能，按投入产出比分为 P0/P1/P2 三档。

---

## 一、衍生版已具备 / 已反超（无需借鉴）

| 能力 | 说明 |
|---|---|
| 多线程分片下载 + 断点续传 | `download_engine.py` 已实现，原版同款 |
| 速度限制 | `max_workers` / `download_limit`，令牌桶式 |
| 音视频分离 / 封装格式 | 支持 mp4/mkv、H.264/H.265/AV1、音频格式 |
| 封面 / 弹幕 / 字幕 / 元数据抓取 | `config.py` 有完整开关与格式选项 |
| 文件冲突策略 / 自动重命名 | `file_conflict_resolution` / `auto_rename` |
| 代理配置 | HTTP 代理 host/port/user/pass |
| 多类型混合选集 + 批量解析 + 搜索联想 | 衍生版已做增强 |
| Windows 系统通知 + 托盘 | `utils/helpers.py` / `utils/tray.py` |
| **直播录制** | 原版明确不支持，衍生版独有 |
| **内置更新（GitHub + 镜像 + 双通道）** | 原版无，衍生版独有 |
| **看板娘 / 反馈页 / 赞助入口 / 工具箱** | 衍生版独有 |
| QThread + QAbstractListModel 原生虚拟化队列 | 架构更现代 |

## 二、值得借鉴的功能清单

### P0 —— 高价值、低成本，建议优先

| # | 功能 | 原版实现位置 | 借鉴要点 | 预估改动 |
|---|---|---|---|---|
| 1 | **批量选集**（输入 `1,3,5-10` 快速勾选） | `dialog/misc/batch_select.py` | 在选集弹窗加一个「批量输入」按钮，解析行号表达式（逗号 + 区间），批量勾选/取消 | 小，1 个对话框 + 解析函数 |
| 2 | **跳转页**（多页结果输入页码直达） | `dialog/misc/jump_to_page.py` | 搜索/选集结果分页控件加「跳至」输入 | 小 |
| 3 | **代理连通性测试**（一键测出口 IP/地区） | `dialog/setting/proxy.py` | 设置页代理卡片加「测试」按钮，请求 `ipinfo.io` 回显 | 小 |
| 4 | **配置导入 / 导出 / 重置 / 打开配置目录** | `gui/interface/setting.py` | 设置页「高级」组加四个按钮，JSON 备份还原；重置保留确认 | 小-中 |
| 5 | **重复下载检测**（检测到重复任务时询问继续/跳过，可不再询问） | `dialog/misc/duplicate_download.py` | 加入队列前比对 download_path 同名文件或 URL 指纹 | 中 |

### P1 —— 有价值、中等成本

| # | 功能 | 原版实现位置 | 借鉴要点 | 预估改动 |
|---|---|---|---|---|
| 6 | **剪贴板监视**（复制链接自动解析，可配是否弹确认） | `dialog/setting/monitor_clipboard.py` | QTimer 轮询剪贴板，识别 B 站链接后自动触发解析 | 中 |
| 7 | **封面查看窗口**（缩放 + 另存 jpg/png/webp） | `dialog/misc/view_cover.py` | 选集/列表右键「查看封面」，独立窗口展示大图 | 中 |
| 8 | **下载优先级拖拽排序**（画质/音质/编码三套） | `dialog/setting/priority.py` | 让现有 `quality_rules` 等从静态列表升级为可视化拖拽排序 | 中-大 |
| 9 | **起始序号**（全局连续编号从 N 开始） | `dialog/setting/starting_number.py` | 下载选项加「起始序号」输入，配合已有编号逻辑 | 中 |
| 10 | **Mica 云母效果 / 显示缩放 100–200%** | `gui/interface/setting.py` | 注：本项目刻意关闭 Mica（与主题系统冲突，见 `fluent_dialog.py` 注释），**仅建议做显示缩放** | 中 |

### P2 —— 深度功能，按需取舍

| # | 功能 | 说明 | 取舍建议 |
|---|---|---|---|
| 11 | **互动视频解析**（自动解析全部分支） | `dialog/misc/interactive_video.py` | 场景小众，解析链路改动大，**暂不建议** |
| 12 | **弹幕 / 字幕 ASS 样式深度自定义** | 字体/颜色/边框/阴影/透明度等 | 已有 `danmaku_format`/`subtitle_format` 基础，可作为长期增强 |
| 13 | **CDN 服务器管理**（节点增删改 + 优先级 + 地区匹配） | 原版完整 CDN 面板 | 衍生版仅直播有简单 CDN 开关；若下载速度受 CDN 影响再做 |
| 14 | **预分配磁盘空间 + 剩余空间校验** | 原版下载引擎 | 属健壮性增强，可在下载引擎优化阶段一并做 |
| 15 | **字幕语言多选 / 下载全部** | 衍生版当前单语言 | 若用户有多语言字幕需求再做 |

## 三、衍生版独有、原版缺失（可作为宣传卖点）

- 直播录制（原版正则注释掉了 `live.bilibili.com`）
- 内置自动更新 + GitHub 镜像 + 稳定/测试双通道
- 看板娘陪伴式弹窗、活泼文案（含 emoji/颜文字，且已纳入 i18n 四语言）
- 软件内反馈页（结构化收集 + 预填 GitHub Issue + 可选代理）
- Q 版工具箱（今日人品等娱乐功能）
- 默认强调色取软件图标粉色 `#f07090`

---

## 四、建议下一步

若继续开发，推荐按 **P0 五项** 打包成一个小版本（如 v2.3.0 次功能更新）：
批量选集 → 跳转页 → 代理测试 → 配置导入导出 → 重复下载检测。
这五项都是「独立对话框 + 少量配置键」，风险低、用户可感知度高，且不与现有主题 / i18n / 虚拟化队列冲突。

> 本报告仅为分析，未改动任何业务代码。是否实施、实施哪几项，请按需决定。
